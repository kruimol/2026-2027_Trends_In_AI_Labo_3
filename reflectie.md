# Reflectie — Studiecoach MCP-server

> Enkel tussentitels en richtvragen. De inhoud vullen we (de twee studenten) zelf in.

## Wat werkte goed?
- Welke onderdelen kwamen snel en betrouwbaar tot stand?
- Merkten we dat Claude Desktop de tools op het juiste moment aanriep (eerst `haal_context_op`)?
- Zag je het antwoord op "Wat moet ik nu doen?" echt veranderen met de context?

## Wat werkte niet of was lastig?
- Waar liepen we vast (opstarten, config, herstarten van Claude Desktop)?
- Riep het model soms de verkeerde tool of géén tool aan? Hoe losten we dat op?
- Wat zouden we anders aanpakken als we opnieuw begonnen?

## Privacy
- Welke persoonlijke gegevens komen in `geheugen.json` terecht?
- Wie kan dat bestand lezen, en is dat erg?
- Wat zou je doen als dit geen schoolprototype maar een echte app was?

## Verouderde context
- Wat gebeurt er als een deadline of zwak punt niet meer klopt?
- Hoe gaat de omgevingslaag om met "voorbij" en "dagen tot"? Is dat genoeg?
- Zou het geheugen oude feiten automatisch moeten opschonen of laten "verlopen"?

## Wat voegt MCP toe?
- Wat kon het model zonder onze server níét, en mét onze server wél?
- Waarom is dit beter dan alles telkens opnieuw in de chat typen?
- Welke andere context zou je via MCP kunnen aanbieden (bv. agenda, cijfers)?
